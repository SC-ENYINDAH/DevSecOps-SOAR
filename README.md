# DevSecOps Pipeline & SOAR Automation Platform

## Objective

Embed security into the software delivery lifecycle and automate vulnerability detection, enrichment, triage, and response.

## Technology Stack

- OWASP Juice Shop
- GitHub Actions
- Semgrep
- Gitleaks
- Trivy
- OWASP ZAP
- Shuffle SOAR
- TheHive

## Workflow

Commit -> Scan -> Gate -> SOAR -> Enrich -> Response
